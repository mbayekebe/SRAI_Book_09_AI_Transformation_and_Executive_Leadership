# Website integration guide

1. Create a feature branch from the current production baseline.
2. Add the lesson migration and unit template.
3. Copy approved public assets and replace placeholder URLs only after verification.
4. Run Django checks, tests, migration dry-run and migration plan.
5. Apply locally, inspect desktop and mobile journeys, then open a controlled pull request.
6. Publish only after the author approves the release candidate and the video URL is verified.
